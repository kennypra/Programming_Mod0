# Mod 0 Programming Bootcamp

Welcome to my **Mod 0 Programming Bootcamp** repository!

This repository documents my work throughout Mod 0 as we get up to speed with the cohort and build a strong programming foundation for coursework in the **Master's of Data Science program at Vanderbilt University**.

## Purpose

Mod 0 is focused on strengthening core programming skills, becoming familiar with the tools and workflows we'll use throughout the program, and preparing for upcoming coursework.

This repository will be used for:

* Coding assignments and exercises
* Programming practice
* Class notes and reference material
* Exploring new concepts and tools

## Goals

By the end of Mod 0, the goal is to have a solid technical foundation, become comfortable working alongside the cohort, and be prepared to take on the programming and computational challenges of the Master's program.

## Repository Structure

The structure of this repository may evolve as Mod 0 progresses, with folders and files organized around assignments, exercises, and notes.
